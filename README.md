# Задание №1 — Численные методы решения нелинейных уравнений

## Описание
Программа решает задачу **численного нахождения корней уравнения** вида **f(x)=0** на заданном отрезке **[A, B]**.

Решение разбито на два этапа:
1) **Отделение корней** (локализация): табулирование отрезка **[A, B]** с шагом  
   **h = (B − A) / N** и поиск **отрезков перемены знака** (где `f(x1) * f(x2) ≤ 0`).
2) **Уточнение корня** на выбранном отрезке перемены знака с точностью **ε > 0** несколькими методами.

Также реализована прикладная часть: **задача о погружении шара**, где для заданного радиуса **r** строится таблица глубины погружения **d** для материалов с разной плотностью **ρ**, используя выбранный метод уточнения корня.

---

## 1) Какую математическую задачу позволяет решить программа?

### 1. Тестовая задача
Найти корни уравнения:
$$
f(x) = x\sin(x) - 1 = 0
$$
на отрезке **[A, B]**, введённом пользователем.

- Отделение корней выполняется табулированием и поиском отрезков перемены знака.
- Затем корень уточняется на одном выбранном пользователем отрезке.

### 2. Задача о погружении шара
Для заданного радиуса **r** найти глубину погружения **d**, решая уравнение (по сути — тоже поиск корня):

$$
\frac{V_{\text{погр}}(d)}{V_{\text{шара}}} - \rho = 0,
$$

где

$$
V_{\text{погр}}(d) = \frac{\pi d^2(3r-d)}{3}, \qquad
V_{\text{шара}} = \frac{4}{3}\pi r^3.
$$

## 2) Какие численные методы используются?
Для уточнения корня на фиксированном отрезке **[a, b]** реализованы 4 метода:

- **Метод бисекции (половинного деления)**
- **Метод Ньютона (касательных)**
- **Модифицированный метод Ньютона**
- **Метод секущих**

## 3) Исходные параметры задачи. Что можно менять? Как вводятся параметры?

### Тестовая задача (f(x)=0)
Ввод с клавиатуры:
- **A, B** — границы отрезка поиска корней;
- **N** — число разбиений (задаёт шаг табулирования: `h = (B - A) / N`);
- **eps (ε)** — точность уточнения;
- **номер отрезка** из списка найденных отрезков перемены знака.

Что можно менять:
- A, B, N (влияют на отделение корней),
- eps и выбранный отрезок (влияют на уточнение).

### Задача о погружении шара
Ввод с клавиатуры:
- **r** — радиус шара (в метрах).

В программе задан список материалов и их плотностей **ρ** (для каждого рассчитывается глубина погружения **d**).

## 5) Представление тестовой задачи (план доклада)

### 5.1 Задача и методы решения
Решается уравнение **f(x)=x·sin(x)−1=0** на отрезке **[A, B]**.  
Сначала выполняется отделение корней табулированием, затем выбранный корень уточняется всеми 4 методами: бисекция, Ньютон, модиф. Ньютон, секущие.

### 5.2 Точный или приближенный метод? Условие остановки
Все методы — **приближенные итерационные**.

- **Бисекция:** цикл продолжается, пока длина отрезка не станет меньше **2·eps**.  
  В программе условие: `(b - a) > 2*eps`.

- **Ньютон / модиф. Ньютон / секущие:** остановка по критерию  
  **|x_new − x| < eps** (или **|x2 − x1| < eps** для секущих).  
  После завершения выводится модуль невязки **|f(x)|** (контроль качества решения).

### 5.3 Нюансы реализации и как они учтены
Возможные проблемы, характерные для итерационных методов:
- **деление на ноль** (Ньютон: `f'(x)=0`; секущие: `f(x1)=f(x0)`);
- **расходимость или зацикливание** метода Ньютона при неудачном начальном приближении.

В моей реализации:
- начальное приближение в Ньютона/модиф. Ньютона берётся как **середина отрезка (a+b)/2**;
- для секущих используются **концы отрезка**: `x0=a`, `x1=b` — как рекомендовано в задании.

*(Примечание: при необходимости можно добавить защиту от деления на ноль и лимит итераций — это типичные улучшения.)*

### 5.4 Проверка правильности (точности) решения
Проверка проводится по:
1) принадлежности найденного корня исходному отрезку;
2) **модулю невязки |f(x~)|** — чем ближе к 0, тем точнее решение.

В программе для каждого метода печатается **невязка** в экспоненциальном виде.

### 5.5 Исходные параметры тестовой задачи
- функция: **f(x)=x·sin(x)−1**
- границы: **[A, B]** (ввод)
- параметры отделения: **N**, шаг **h = (B − A) / N**
- точность уточнения: **eps**

### 5.6 Что выводит программа и как анализировать результаты
После отделения корней программа выводит:
- количество отрезков перемены знака и сами отрезки с нумерацией;
- шаг табулирования **h**.

После уточнения корня выводится таблица:
- метод,
- число шагов,
- приближенный корень (15 знаков),
- модуль невязки.

По результатам можно сравнить:
- **скорость** (меньше шагов — быстрее),
- **точность** (меньше невязка — лучше).
